# Neighborhood Frontend

- Пиши ответы и интерфейс на русском; идентификаторы и комментарии в коде — на английском.
- Стек: стабильный React, TypeScript, Redux Toolkit / RTK Query, React Router, Ant Design, Vite. React не выпускает отдельные LTS-релизы; используй стабильный Latest, Node.js — LTS 24.
- **Используй готовые библиотеки компонентов. Не создавай собственные базовые UI-компоненты (кнопки, поля, модальные окна, селекты, карточки, навигацию и т. п.).** Собирай страницы и предметные формы из Ant Design; иконки бери из @ant-design/icons. Собственные композиции для бизнес-сценариев допустимы.
- Поддерживай мобильные и настольные экраны; основной цвет — синий. Уважай prefers-reduced-motion, обеспечивай доступность форм и клавиатурной навигации.
- Сверяй DTO и правила с ../neighborhood/docs и Java-контроллерами. Не добавляй несуществующие API, фиктивные данные и неподдерживаемые действия.
- Данные сервера и кэш — RTK Query, сессия — Redux. Не сохраняй токены и пароли в localStorage, URL или логах. Токены живут только в памяти.
- Не меняй соседний backend в рамках frontend-задач без необходимости и согласования публичных контрактов.
- Перед завершением запускай npm test, npm run build и доступные браузерные проверки. Фиксируй ограничения проверки честно.
- Не создавай коммиты, не отправляй код и не развёртывай приложение без явного запроса.
